    AI assistant

    The chat assistant (the popup's ✦ button) plans focus / open / attach actions over the images scanned from the current page. Configure which LLM it talks to — see llm-contract.md.

    Pre-filled with the provider's default (http://localhost:11434 for Ollama, http://localhost:1234/v1 for OpenAI-compatible); edit freely.     Sent as Authorization: Bearer on OpenAI-compatible providers only. Stored in chrome.storage.local on this machine.
