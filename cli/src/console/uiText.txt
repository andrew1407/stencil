# Console prose, kept out of ui.zig so the wording is one block of text, not 120 lines of
# literals. Blocks start with '@name'; '#' lines here are the header only. In @help a blank
# line is blank, '§' starts a section heading (accent-coloured) and a TAB splits a command
# from its description — ui.zig lays the columns out. Rendered byte-for-byte into the pins in
# tests/pins/{intro,help,filters}.*.txt, and cross-checked against the command table by
# tests/repl_text_test.zig.
@intro
Console mode — '/command <args>' (the '/' is optional). Tab completes, Up/Down
recall history; Ctrl-V pastes the clipboard — an image attaches to the line you are typing
(Backspace over its marker takes it back), text is simply typed. '/help' lists
commands, '/theme' changes colour, '/mouse' switches between the terminal's own text
selection and the in-app one, '/exit' (or Ctrl-C twice) leaves.
@intro-fullscreen
Console mode — '/command <args>' (the '/' is optional). Tab completes, Up/Down
recall history; Ctrl-V pastes the clipboard (an image attaches to the line, text is typed),
Ctrl-C copies the selection. '/help' lists commands, '/exit' leaves.
@mouse-app
drag to select (Ctrl-S copies) — for the TERMINAL's own selection hold Shift while dragging (macOS VS Code: Option, with terminal.integrated.macOptionClickForcesSelection on), or '/mouse off'
@mouse-terminal
the terminal owns the mouse — its own selection and copy work; '/mouse on' switches to the in-app accent one (Ctrl-S copies)
@filters
Filters — '/filter <mode>' to apply:
   bw        greyscale
   sepia     warm brown tone
   invert    negative (flip every channel)
   contour   edge detection (dark edges on white)
   none      remove the filter
   <colour>  a name or #hex makes a duotone tint (e.g. '/filter teal')
@help
Commands  (a leading '/' is optional)

§Image
/upload <path|url>	load an image or video frame (bare: the clipboard's picture)
/source-upload <url> [i] [fmt] [name=]	scrape a page and load its i-th image (alias /scrape)
/paste	load an image from the clipboard (Ctrl-V pastes onto the line instead)
/unpaste [n]	take back an image added this turn (bare = the last; Ctrl-Z)
/images	list the images this turn will send to the assistant
/blank [fmt] [w h] [color]	create a blank page (default: the picked format or A4, white)
/format [name|custom w h]	list the page formats or pick one (drives /blank + the layout)

§Edit
/apply <file.json>	draw a layout JSON onto the image
/crop <spec> [album]	crop, e.g. "x1=10% x2=90% y1=10% y2=90%"
/rotate <int>	rotate int*90 degrees (e.g. -1, 2, 3)
/filter <mode>	bw | sepia | invert | contour | none | a colour name/#hex (tint)
/exec <action> ...	run a transform by name (crop | rotate | filter | apply)
/script <directives>	run a .stc script on this image (';' separates statements)
/script-run <file.stc>	run a .stc script file on this image
/undo   /redo	step back / forward through edits
/reset	revert to the original, dropping all edits

§Save
/save [path]	write to a file; a bare /save pushes to the active server project
/delete <file.stencil>	delete a local .stencil project file from disk
/layout [path]	save the layout JSON (bare = <project>.json; a dir saves <project>.json there)
/formula [x|y <expr>|on|off|clear]	set the x/y coord-transform formulas (saved in the layout)
/copy	copy the current image to the clipboard

§Connections
/connect <url [token]>	connect to collaboration servers (token: session or admin, for gated servers)
/connections [admin|session]	list connected servers + reachability status (filter by credential)
/disconnect [url]	close a connection (or the most recent)
/reconnect [url]	re-establish one connection (or all) and the live feed
/projects [url]	list projects on a server (or all connected servers)
/project-color [#hex]	show or set the active project's name colour (clear = neutral grey)
/blank-color [#hex]	show or recolour a BLANK project's background fill (blanks only)
/rename <name>	rename the active server project (pushed live to peers)
/keywords <project>	show a server project's search keywords (by name)
/keywords-search <kw...>	list projects across servers matching any keyword
/keywords-add <project|[..]> <kw...>	add keywords to one or more projects
/keywords-del <project|[..]> <kw...>	remove keywords from one or more projects
/expire [<duration>]	set when the active project expires (bare = formats; e.g. 'months 3', 'off')
/fetch <name> [url]	load a server project's image to keep editing
/sync [on|off]	live mode (bare /sync toggles): push edits + pull peers' changes

§Assistant
/prompt <text>	ask the LLM assistant; it plans + runs edits and renders variant-<label>.png files (alias /p)
/llm [key <value>]	show or set the LLM provider config (provider | url | model | key | server; env STENCIL_LLM_*)
/chat [on|off|clear]	opt-in: save the /prompt conversation with the project + replay it (bare /chat shows; default off)

§System
/status	show the working image (path, size, edit position)
/theme [name]	list or switch the accent colour (default violet)
/mouse [on|off]	full-screen: toggle mouse (off frees text selection)
/reveal-speed [0.01-1]	full-screen: how fast output is revealed (1 = instantly, 0.5 default)
/clear	clear the screen, redraw the logo + image header
/drop	forget the working image entirely
/help   /exit	show this list / leave (Ctrl-D, or Ctrl-C twice)

¶Shortcuts  Ctrl-V paste the clipboard — an image attaches to the line (3 on a /prompt,
           1 on an /upload; Backspace removes it), text is typed straight in
           Ctrl-C copy the selection (nothing selected: press twice to exit) · Ctrl-S also copies
           Ctrl-Z un-attach/un-paste · Ctrl-Alt-C copy the image to the clipboard
           Ctrl/Alt-Backspace delete the word back · Alt-d or Ctrl/Alt-Delete the word ahead
