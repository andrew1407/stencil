Download one file a project stores on a Stencil collaboration server. `kind` is `original` (the source image), `result` (the rendered edit), `video`, `chat` (the saved assistant chat, JSON) or `variant1`…`variant8` (the assistant's variants); `stencil_projects` with `id` and `files` lists which ones the project holds and their formats. Name the project by its `id` (`p_…`). The file is written to `output` byte for byte as the server stores it — nothing is decoded or converted, so give `output` the extension of its format. The `output` must sit inside the server's roots (the client's workspace roots, else the operator's); a relative path resolves against the first root; `overwrite` defaults to false. Only servers the operator allowlisted are reachable: `server` names one (omit it when exactly one is allowed), and the operator's token for it is used automatically — it is never a parameter. Returns the server's origin, the project id, the kind, the written path, its size in bytes and the format its first bytes name.
