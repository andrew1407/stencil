Edit one image or video frame with Stencil's core pipeline (source → crop → rotate → filter → draw layout → encode) and write the result to a file, then deliver it to the selected surface(s). Provide either `input` (a path or http(s) URL) or `blank` (a fresh canvas), plus any of crop/rotate/layout/filter, an `output` path, and an optional `surface` override. `rotate` counts quarter-turns (1 = 90°); `layout_frame: "source"` reads the layout's coordinates in the input's frame, before the crop and rotate. The `output` must sit inside the server's roots (the client's workspace roots, else the operator's); a relative path resolves against the first root; an output ending in `.stencil` bundles a project instead of an image. To work with a Stencil collaboration server — only one the operator allowlisted: set `server` to its URL and `input` to a project NAME to fetch and edit it (`stencil_projects` lists the names), add `remote_update` to write the result back; or set `remote` (a server URL) + optional `remote_name` to push the result as a NEW project. `server` and `remote` may point at different servers, so one call can fetch from one and publish to another. The result is always saved locally too. Set `preview` to also get the written image back as a PNG thumbnail (longer side at most 512 px) in an image content block, to check the edit by eye. Returns the written path, final dimensions, per-surface delivery notes, and any server projects updated/created.
