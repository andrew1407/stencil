Rewrite a Stencil script (`.stc`) as a runnable file for another surface, without running it. The `output` file's extension picks the target: `.js`/`.stcjs` for the browser editor's `window.stencil` console facade, `.py`/`.pystc` for the pystencil Python package. Templates are expanded and undo/redo resolved; lengths, sources and save targets are written as the script wrote them. Pass the source as `script_text` (inline .stc, up to 256 KiB) or `script_path` (an existing .stc file) — exactly one. The `output` must sit inside the server's roots (the client's workspace roots, else the operator's); a relative path resolves against the first root; `overwrite` defaults to false. A directive the target cannot honour is refused with the CLI's error. Returns the written path and its target.
