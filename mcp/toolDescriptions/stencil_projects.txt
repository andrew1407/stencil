List the projects on a Stencil collaboration server, or read one project's metadata by `id` — the project NAMES are what `stencil_edit` fetches with `server` + `input`. Only servers the operator allowlisted are reachable: `server` names one (omit it when exactly one is allowed), and the operator's token for it is used automatically — it is never a parameter. Page a listing with `limit` (1–500, default 50) and `after` (the previous page's `next_cursor`). With `id`, set `files` to also list the files the project stores — `original`, `result`, `video`, `chat`, `variant1`…`variant8` — each with the format its first bytes name; `stencil_project_file` downloads one. Read-only: no image or layout is downloaded. The read runs through the Stencil CLI, so http:// and https:// servers both work. Returns the server's origin, the projects (id, name, timestamps, image size, description, keywords, source, colours, expiry, version — and with `files`, the files) and the next cursor.
