Run a Stencil script (`.stc`) — the batch language for image edits, parsed and lowered by the shared core (see contracts/stc/stc-contract.md). A script names its own inputs with `@source <file|url|dir/|glob>:` blocks and its own outputs with `@save`, so ONE call can edit a whole directory: `@crop`, `@filter`, `@line`/`@rect`, `@layout`, `@frame`, `@undo`/`@redo`, `@use` for units and line style, and `@stencil` templates. Pass the source as `script_text` (inline .stc, up to 256 KiB) or `script_path` (an existing .stc file) — exactly one. A script with no `@source` block edits the `input` image instead. Every `@save` is confined to `output_dir` (created if missing; defaults to the current directory), so write RELATIVE targets: `@save out/` or `@save shot.png`, never an absolute path — a bare `@save` next to an absolute source is refused by the sandbox, and a `@save` into a subdirectory needs that directory to already exist. A script with any diagnostic error runs nothing and the whole call fails with the CLI's `file:line:col: error: … [CODE]` lines. Returns every file written with its pixel dimensions, plus any notes the run printed.
