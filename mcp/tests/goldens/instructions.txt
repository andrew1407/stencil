Stencil image/video editing. `stencil_edit` runs the full pipeline (source → crop → rotate → filter → layout → encode), writes a file, and delivers it to the configured surface(s) — cli (file), desktop (launch the Qt app), browser (editor launch URL); pass `surface` to override per call. Every write lands inside the server's roots — the client's workspace roots, else the operator's STENCIL_MCP_ROOTS, else its working directory — and a relative path resolves against the first root. It can also work with the Stencil collaboration servers the operator allowlisted (STENCIL_MCP_SERVERS): `stencil_projects` lists a server's projects (and the files one stores), `stencil_project_update` changes a project's metadata, `stencil_project_file` downloads one of its files, `server`+`input` fetches a project by name to edit, `remote_update` writes the result back, and `remote` (+`remote_name`) publishes the result as a new project — `server` and `remote` can be different servers in one call. `stencil_probe` returns an image's pixel size, format and alpha, or a video's length. `stencil_script` runs a Stencil script (`.stc`) — the batch language: `@source` blocks over files, directories or globs, `@crop`/`@filter`/`@line`/`@rect`/`@layout`/`@frame`/`@undo` ops, `@stencil` templates, and `@save` targets confined to `output_dir`, so one call edits many files; `stencil_script_check` and `stencil_script_plan` validate and preview a script without running it, and `stencil_script_emit` rewrites it for the browser editor or pystencil. `source_site` scrapes a web page and downloads its matching media (filter by category/format/dimensions, page with count/group) into a directory. `stencil_prompt` hands a natural-language request (plus the input image, for vision) to a configured LLM — ollama, openai-compat, or a stencil-server Anthropic proxy, via the STENCIL_LLM_* env keys, plain http:// only — and runs the strictly validated op-plan it returns through the same pipeline, writing {output_dir}/result.png plus one file per variant. The op registry, the .stc contract, page formats, colours and filters are resources; the prompts draft a .stc script and lay out a print page. Coordinates in layouts and crops are image pixels. The server shells out to the Stencil CLI, so set STENCIL_CLI if the binary isn't found in the checkout this server was built in or on PATH.
