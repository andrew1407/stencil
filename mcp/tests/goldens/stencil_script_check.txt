Check a Stencil script (`.stc`) without running it: the shared core parses and lowers it and every diagnostic comes back — line, column, severity, the stable code from the stc contract's catalogue, and the message. Pass the source as `script_text` (inline .stc, up to 256 KiB) or `script_path` (an existing .stc file) — exactly one. Nothing is fetched, run or written. Returns `valid` (false when any diagnostic is an error), the error and warning counts, and the diagnostics in source order.
