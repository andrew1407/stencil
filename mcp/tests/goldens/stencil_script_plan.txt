Preview a Stencil script (`.stc`) as the op-plans a run would execute, without running it: for each `@source` block, the expanded input files, the validated actions (in the opRegistry.json vocabulary) and the concrete path of every `@save`. Pass the source as `script_text` (inline .stc, up to 256 KiB) or `script_path` (an existing .stc file) — exactly one. Add `input` for a script with no `@source` block; its header sizes the shape ops. Nothing is written. A local input's header is read; an http(s) input is fetched, through the CLI's fetch guard, only when its block draws lines that need its size, and an `@layout` URL is fetched to plan its lines. A script with any error returns its diagnostics and no blocks.
